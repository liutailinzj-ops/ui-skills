# Research Method

## Source set

Use the customer's competitor/reference URLs first. Supplement them with current first-party sites from the same category and target market.

Aim for a compact evidence set:

- 2–4 direct competitors or close category peers.
- 1–2 strong reference sites with relevant presentation patterns.
- The theme demo or existing site when applicable.

## Analyze

For each source, record only decision-useful observations:

- Information hierarchy.
- Product/category presentation.
- Trust and proof patterns.
- Navigation and discovery model.
- Desktop/Mobile differences visible from the site.
- Patterns repeated across the category.
- Opportunities to avoid sameness.

## Do not copy

- Do not reproduce a competitor's full sequence, copy, brand assets, or distinctive visual identity.
- Translate observations into reusable content responsibilities and layout principles.
- Clearly label inferences and unavailable evidence.

If browsing is unavailable, use supplied references, state the limitation, and avoid presenting memory-derived trend claims as current research.
