# 内部 QA 报告模板

默认在 Codex 对话或内部文档中返回，不要写入客户预览 Frame。

```markdown
## 检查结果

- Figma 文件：
- Desktop 页面：
- Mobile 页面：
- 总体状态：通过 / 需要调整 / 阻塞
- 视觉方向一致性：
- 来源页面一致性：
- 主题模块映射：
- Figma 结构：
- Desktop/Mobile 响应式：
- 客户预览隔离：

## 视觉检查

- 字体层级：
- 颜色与品牌气质：
- 图片风格与裁切：
- 页面密度与留白：
- 模块构图：
- 是否出现通用模板回退：

## 来源与主题

- 指定结构来源：
- 主题能力来源：
- 内容与布局对应：
- 主题原生实现：
- 主题适配：
- 需要二次开发：

## Figma 结构检查

- Text Style：
- Variables：
- Components：
- Auto Layout：
- 网格与对齐：
- 父子节点包含：
- 文本裁切或重叠：
- Mobile 溢出：

## 已自动修复

- {节点或模块}：{修复内容}

## UI 需要调整

- {设计或内容事项}

## 客户资料待补充

- {占位内容}：{需要替换的资料}

## 开发实现风险

- {模块}：{风险和处理建议}

## 阻塞问题

- {问题和负责人}
```

删除空章节。所有可见标题、状态和说明使用中文；网站设计本身继续使用项目约定的网站语言。
