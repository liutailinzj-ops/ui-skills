# 内部 QA 报告模板

默认在 Codex 对话或内部文档中返回，不要写入客户预览 Frame。

```markdown
## 检查结果

- Figma 文件：
- Desktop 页面：
- Mobile 页面：
- 代表性模块预检：未运行 / 通过 / 需要调整 / 阻塞
- Desktop 完整预览：未运行 / 通过 / 阻塞
- Mobile 完整预览：未运行 / 通过 / 阻塞
- 总体状态：进行中 / 通过 / 需要调整 / 阻塞
- 视觉方向一致性：
- 视觉签名证据：
- 来源页面一致性：
- 主题模块映射：
- 目标模板：已提供 {theme} / 未提供，已自动匹配 {theme} / 纯定制不适用
- Figma 结构：
- 文件页面卫生：{总页数} 页 / {有效页数} 页 / 空页面 {0} / 待清理工作页 {0}
- 响应式 Section 配对：
- 客户预览隔离：
- 组件库排列：
- Section 视觉质量：
- 整页构图与节奏：
- 内容策略与产品相关性：

## 视觉检查

- 字体层级：
- 颜色与品牌气质：
- 图片风格与裁切：
- 页面密度与留白：
- 模块构图：
- 是否出现通用模板回退：

## 来源与主题

- 指定结构来源：
- 主题能力来源：
- 内容与布局对应：
- 主题原生实现：
- 主题适配：
- 需要二次开发：

## Figma 结构检查

- Text Style：
- Variables：
- Components：
- Auto Layout：
- 网格与对齐：
- 同组边界差值：
- 父子节点包含：
- 文本裁切或重叠：
- 断点内容一致性：
- 客户可见内容账本：
- 内部标记泄漏：
- 断点溢出与裁切：
- 组件库分类与行对齐：
- 组件集边界与排列：
- 空页面与工作残留：

## 内容与整页检查

- 产品与品类理解：
- 竞品呈现逻辑：
- 页面转化/购买链路：
- Section 内容差异：
- 整页栅格与对齐：
- 色彩、图片与密度分布：
- 默认审美风险：

## 已自动修复

- {节点或模块}：{修复内容}

## UI 需要调整

- {设计或内容事项}

## 客户资料待补充

- {占位内容}：{需要替换的资料}

## 开发实现风险

- {模块}：{风险和处理建议}

## 阻塞问题

- {问题和负责人}
```

删除空章节。所有可见标题、状态和说明使用中文；网站设计本身继续使用项目约定的网站语言。
